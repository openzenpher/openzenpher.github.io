# zenpher
![](game/title.png)
zenpher is a social game where you can customize your blob...
...yes its that simple, or is it?
you can apply for a j*b, absolutely FORCE it to do tasks, provocate chaos, etc etc etc.

## welcome!
welcome to zenpher, a social game where you do tasks, maybe roleplay and probably be whatever u wanna be!

## note
zenpher is still on beta, everything IS expected to fall apart. it is written on PurrScript (https://permafy.org/), this means it's as much as unstable as the programming language.
it's made by aynonyaz and it's licensed on gpl-3.0 license.
